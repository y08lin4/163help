一、安装

以下两种方式任选其一，均可正常使用互助功能。

方式一：油猴脚本（需安装 Tampermonkey）

  1. 安装浏览器插件 Tampermonkey（油猴）
  2. 打开下方脚本地址，Tampermonkey 会弹出安装确认，点「安装」
  3. 如果浏览器直接显示源码，复制地址到 Tampermonkey 的「从 URL 安装」
安装脚本 /music-help.user.js

方式二：浏览器扩展（无需油猴）

扩展是油猴脚本的独立移植版，不需要安装 Tampermonkey。额外功能：开机自启 + 标签静音（只静音网易云音乐标签，其它标签不碰）。

  1. 下载最新安装包 163help-extension-v5.0.0.zip（最新版直接下载，无需 GitHub）
  2. 解压，会得到一个 extension/ 文件夹
  3. Chrome 打开 chrome://extensions，点击右上角「开发者模式」
  4. 点「加载已解压的扩展程序」，选择 extension/ 文件夹（就是直接包含 manifest.json 的那一层）
下载 163help-extension-v5.0.0.zip /163help-extension-v5.0.0.zip?v=20260903

提示：扩展和油猴是两套独立存储，切换过去需要重新登录一次。

二、Docker 常驻客户端（VPS 24 小时在线互助）

把客户端放进 Docker 容器，在 VPS 上 24 小时常驻互助——无需打开浏览器，无头浏览器（Playwright Chromium）真实播放，一个容器 = 一个网易云账号。当前 Docker 客户端版本 v5.0.0。

一键脚本（自动选择镜像通道）

脚本默认先试 GitHub GHCR、失败自动切换 Cloudflare CDN；国内 VPS 可用 IMAGE_SOURCE=cdn 强制走 CDN（免登录，更稳）。

curl -fsSL https://raw.githubusercontent.com/y08lin4/163help/main/client-docker/scripts/vps-setup.sh -o vps-setup.sh
chmod +x vps-setup.sh
UI_PASSWORD='你的强密码' ./vps-setup.sh

手动安装：双通道任选其一（宿主端口默认 13000，避免与常用服务冲突）

通道 A：GitHub GHCR（海外推荐）

镜像已公开、匿名可拉取，无需 docker login。

docker run -d \
  --name 163music-docker-client \
  --restart unless-stopped \
  --memory 1g \
  -e UI_PASSWORD='你的强密码' \
  -e TZ=Asia/Shanghai \
  -p 13000:3000 \
  -v ./data:/data \
  ghcr.io/y08lin4/163music-help/docker-client:docker-v5.0.0

Github Release：v5.0.0

通道 B：Cloudflare CDN 镜像包（国内推荐）

从本站下载 163music-docker-client-latest.tar.gz（当前为 v5.0.0），离线导入：

# 下载后执行
docker load -i 163music-docker-client-latest.tar.gz
docker run -d \
  --name 163music-docker-client \
  --restart unless-stopped \
  --memory 1g \
  -e UI_PASSWORD='你的强密码' \
  -e TZ=Asia/Shanghai \
  -p 13000:3000 \
  -v ./data:/data \
  ghcr.io/y08lin4/163music-help/docker-client:docker-v5.0.0
下载镜像包（882MB） /docker/163music-docker-client-latest.tar.gz

三、使用

  1. 打开网页版 music.163.com（不是客户端）
  2. 页面右侧出现「🎵 互助面板」，点「我已阅读并确认」
  3. 点「登录 Linux.do」，完成授权
  4. 输入歌曲 ID（每行一个，如 song:123，也可直接填数字 123，仅支持单曲）
  5. 点「开启互助」，脚本自动帮你播放 + 帮别人播放

单曲 ID 在哪找

  • 单曲：歌曲页网址里的 song?id=xxx

面板功能

功能说明
偏好选择短歌优先 / 长歌优先 / 随机
只帮不助歌曲列表留空 = 只帮别人赚积分，不加入被助队列
自动开启勾选后，配合浏览器主页实现「开浏览器就互助」

四、积分与规则（v5 按秒体系）

积分

1 点 = 1 秒播放时长。帮助者每听 1 秒赚 1 点，被助者每被听 1 秒扣 1 点，平台抽 5% 税。

帮听限额（按秒）

限制规则
帮听秒上限9,000 秒/天（= min(你最长歌, 300 秒) × 30，无歌=系统基准）
每小时最多 30 次；同歌 5 分钟冷却；休息窗口随机 30~60 分钟
心跳播放期间持续上报心跳；无心跳的播放视为无效（任务会按规则过期，需重新听）
熔断保护连续异常（无心跳过期）会暂停派单，完成任一播放即自动恢复

被助限额（按次数）

限制规则
被助次数26 次/24 小时、700 次/30 天
最多挂歌默认 3 首，可在「个人中心」申请增加（上限 20）
先帮后助不强制（服务器当前配置为不要求先帮过）

派发优先级

按「活跃帮听者 + 公平保底 + 系统歌缺口补位」加权抽签：活跃度高的帮听者权重更高，长期等待者获公平加成；空闲时段由系统歌（系统账号公开曲库）补位，保证随时有单可接。
