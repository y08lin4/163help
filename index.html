一、安装

以下两种方式任选其一，均可正常使用互助功能。

方式一：油猴脚本（需安装 Tampermonkey）

  1. 安装浏览器插件 Tampermonkey（油猴）
  2. 打开下方脚本地址，Tampermonkey 会弹出安装确认，点「安装」
  3. 如果浏览器直接显示源码，复制地址到 Tampermonkey 的「从 URL 安装」
安装脚本 /music-help.user.js

方式二：浏览器扩展（无需油猴）

扩展是油猴脚本的独立移植版，不需要安装 Tampermonkey。额外功能：开机自启 + 标签静音（只静音网易云音乐标签，其它标签不碰）。

  1. 下载最新安装包 163help-extension-v4.0.18.zip（最新版直接下载，无需 GitHub）
  2. 解压，会得到一个 extension/ 文件夹
  3. Chrome 打开 chrome://extensions，点击右上角「开发者模式」
  4. 点「加载已解压的扩展程序」，选择 extension/ 文件夹（就是直接包含 manifest.json 的那一层）
下载 163help-extension-v4.0.18.zip /163help-extension-v4.0.18.zip?v=20260816c

提示：扩展和油猴是两套独立存储，切换过去需要重新登录一次。

二、Docker 常驻客户端（VPS 24 小时在线互助）

把客户端放进 Docker 容器，在 VPS 上 24 小时常驻互助——无需打开浏览器，无头浏览器（Playwright Chromium）真实播放，一个容器 = 一个网易云账号。当前 Docker 客户端版本 v4.0.18。

一键脚本（自动选择镜像通道）

脚本默认先试 GitHub GHCR、失败自动切换 Cloudflare CDN；国内 VPS 可用 IMAGE_SOURCE=cdn 强制走 CDN（免登录，更稳）。

curl -fsSL https://raw.githubusercontent.com/y08lin4/163help/main/client-docker/scripts/vps-setup.sh -o vps-setup.sh
chmod +x vps-setup.sh
UI_PASSWORD='你的强密码' ./vps-setup.sh

手动安装：双通道任选其一

通道 A：GitHub GHCR（海外推荐）

镜像已公开、匿名可拉取，无需 docker login。

docker run -d \
  --name 163music-docker-client \
  --restart unless-stopped \
  --memory 1g \
  -e UI_PASSWORD='你的强密码' \
  -e TZ=Asia/Shanghai \
  -p 3000:3000 \
  -v ./data:/data \
  ghcr.io/y08lin4/163music-help/docker-client:latest

通道 B：Cloudflare CDN tar（国内推荐）

下载 tar 包 + docker load，无需登录任何 registry，国内拉取更稳。

curl -fSL -o /tmp/163music-docker-client.tar.gz \
  https://163music.linyu.qzz.io/docker/163music-docker-client-latest.tar.gz
docker load -i /tmp/163music-docker-client.tar.gz
# 然后执行上面「通道 A」的 docker run 命令（同一镜像名）即可
  • UI_PASSWORD 必设强密码：管理界面登录用，未设置容器会拒绝启动
  • 管理界面：http://IP:3000，粘贴网易云 Cookie + portal 客户端密钥（mh_ck_ 开头）即可长期运行；宿主机端口冲突时自行映射，如 -p 13000:3000
  • -v ./data:/data 数据卷持久化，升级不丢数据；升级 = pull 新镜像 + docker rm -f + 相同数据卷重建
  • 完整说明见 GitHub 仓库 y08lin4/163help · client-docker 目录

三、使用

  1. 打开网页版 music.163.com（不是客户端）
  2. 页面右侧出现「🎵 互助面板」，点「我已阅读并确认」
  3. 点「登录 Linux.do」，完成授权
  4. 输入歌曲 ID（每行一个，如 song:123，也可直接填数字 123，仅支持单曲）
  5. 点「开启互助」，脚本自动帮你播放 + 帮别人播放

单曲 ID 在哪找

  • 单曲：歌曲页网址里的 song?id=xxx

面板功能

功能说明
偏好选择短歌优先 / 长歌优先 / 随机
只帮不助歌曲列表留空 = 只帮别人赚积分，不加入被助队列
自动开启勾选后，配合浏览器主页实现「开浏览器就互助」

四、派发与概率规则

积分（按秒计费）

1 点 = 1 秒播放时长。帮助者每听 1 秒赚 1 点，被助者每被听 1 秒扣 1 点，严格守恒。

派发规则（积分档位加权随机抽签）

每次从所有符合条件的候选中按积分档位权重加权随机抽签（不是严格排序），余额越高被抽中的概率越大，但按档位封顶：

  • 余额 ≥ 9000：权重 1.2
  • 余额 ≥ 3600：权重 1.1
  • 余额 ≥ 900：权重 1.0
  • 其余：权重 0.8
  • 用户偏好（短歌/长歌/随机）做轻微倾斜，不改变积分权重的主导地位

限额（按次数）

限制规则
单曲每日被播30 次/天
单用户每日被助30 次/天
月度被助700 次/月
最多挂歌默认 3 首，可在「个人中心」申请增加（上限 20）
帮过才被助已取消（服务器当前配置 MIN_HELPS_BEFORE_RECEIVING=0，不要求先帮过）

防风控

  • 连续播放 30~60 分钟（随机）后自动休息一下
  • 同一首歌 5 分钟内不重复派发
  • 改歌（换歌）需要管理员审核
